# 『갈라디아서 산책』 블로그 연재

권연경의 『갈라디아서 산책』을 근거로 작성한 17편의 블로그 연재다. 각 글은 독립적으로 게시할 수 있으며, 전체 순서대로 읽으면 책의 논증이 다음 흐름으로 이어진다.

> 상황 속의 복음 → 갈라디아 교회의 위기 → 믿음과 성령 → 율법과 자유 → 바울의 체험적 호소 → 새 창조와 그리스도의 형상

## 작성 형식

- 각 문단의 주제를 번호가 붙은 소제목으로 표시한다.
- 성경 문장은 직접 인용하지 않고 `(갈 3:1–5)`처럼 주소만 괄호 안에 표시한다.
- 본문에서는 저자의 이름을 반복하지 않고 내용을 통합하여 서술한다.
- 각 글에는 결론과 다음 글 안내를 두며, 마지막 글은 연재 전체의 결론으로 마친다.
- 외부 자료를 섞지 않고 『갈라디아서 산책』의 논지를 따른다.

## 23편 연재

『갈라디아서 산책』의 스물세 걸음을 순서대로 따라가는 연재다. 위의 17편과 별도로 독립된 시리즈이며, 각 글은 번호가 붙은 소제목과 결론, 다음 글 안내를 갖춘다.
