# 갈라디아서 산책 연재 23편

갈라디아서는 짧은 편지다. 그러나 이 편지 안에는 복음이 무엇이고 무엇이 복음이 아닌지, 믿음과 성령과 율법이 어떻게 이어지는지, 그리스도인의 자유가 어디로 향하는지가 압축되어 있다. 이 연재는 편지의 구절을 순서대로 풀이하지 않는다. 대신 갈라디아 교회에 무슨 일이 있었는지, 바울은 그 일을 어떻게 보았는지, 왜 믿음이 답이고 왜 성령이 열쇠인지, 율법은 무엇이고 자유는 무엇인지를 하나씩 물으며 편지 전체를 걷는다. 모두 스물세 편이며, 다음 순서로 이어진다.

> 상황 속의 복음 (1-4편) → 바울의 신학적 대응 (5-10편) → 성경과 율법 (11-14편) → 바울의 체험적 호소 (15-19편) → 다시 생각하는 갈라디아서 (20-23편)

성경 본문은 직접 인용하지 않고 괄호 안에 주소만 적었다. 별도 표시가 없는 주소는 갈라디아서다.
