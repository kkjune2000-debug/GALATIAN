# GALATIAN

갈라디아서의 본문과 주제를 이해하기 쉽게 정리하고, 발표용·인쇄용 결과물을 함께 관리하는 저장소다.

## 작업 원칙

- 별도의 지시가 없는 한 권연경의 『갈라디아서 산책』만을 기본 출처로 사용한다.
- 다른 다섯 권의 PDF나 외부 자료는 사용자가 별도로 지시할 때만 사용한다.
- 저자의 이름이나 주장을 본문에서 반복하기보다 내용을 통합하여 서술한다.
- 중요한 인용과 해석상의 차이는 각주 또는 참고도서에서 밝힌다.
- 원문 PDF는 저장소에 포함하지 않고, 이를 바탕으로 작성한 결과물만 관리한다.
- 본문은 문어체로 작성하고, 이해하기 쉬운 논리 구조를 유지한다.
